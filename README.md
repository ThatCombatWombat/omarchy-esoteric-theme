
# Esoteric

An esoteric / occult-inspired theme for [Omarchy](https://omarchy.org/).

## Installation

Install directly from your terminal:

```bash
omarchy-theme-install https://github.com/ThatCombatWombat/omarchy-esoteric-theme.git
```

Or open the Omarchy menu with `Super + Alt + Space` and go to:

**Install → Style → Theme**

Then paste:

```text
https://github.com/ThatCombatWombat/omarchy-esoteric-theme.git
```
